# PR 전 검증 결과

검증일: 2026-10-18. Python·Spring 로컬 변경 기준. PR 생성·커밋·원격 푸시는 수행하지 않았다.

실제 API 실행 1회 소요시간은 약 6.66초. 성능 통계나 운영 SLA로 사용하지 않는다. 모델 호출의 답변 존재와 후보 ID·필터만 확인했으며 문장별 사실성은 정량 평가하지 않았다.

## 검토 중 발견해 수정한 문제

1. 여러 지역을 자유문장에 쓰면 조건이 사라져 전국 추천될 수 있었음. 지역 선택 안내·빈 후보 반환으로 변경하고 HTTP 회귀 테스트 추가.
2. `0원 미만`이 0원으로 보정되어 무료 체험을 허용할 수 있었음. 유효한 비음수 상한으로 추정하지 않도록 수정. 음수 표현을 양수로 파싱하지 않는 사례도 추가.
3. 예산 확인 안내에 내부 필드명 `maxPrice`를 노출하던 문구를 사용자 표현으로 수정.
4. 변경 파일의 미사용 import·지역변수를 정리해 Ruff 통과.

## PR·배포 범위

- Python 저장소: 필터·근거 모델·마이그레이션·내부 API·로컬 검증 스크립트·문서.
- Spring 저장소: 요청/응답 확장·조건 전달·fallback 조건 보존·회귀 테스트. 기존 후기 테스트의 컴파일을 막던 누락 import 1건도 수정.
- 배포는 AI 스키마 마이그레이션 및 Python API 반영 후 Spring 순서로 진행. 구버전 Python은 새 optional 필드를 무시할 수 있어 Spring만 먼저 배포하면 가격·기술 조건 보장이 안 됨.
- 기존 로컬 DB는 Alembic 이력이 없는 legacy 스키마여서 보완 도구를 사용했다. 이를 운영 배포에 그대로 사용하거나 무조건 stamp하지 않는다. 운영 DB의 현재 리비전·스키마를 확인한 뒤 정상 migration 경로를 적용해야 함.
- PR 준비는 가능하나 앱 전체 기능 완성이나 전국 실데이터 추천 정확도를 주장할 수 없음.

## 남은 한계

- 자유문장 조건 해석은 제한적 한국어 패턴이다. 모든 시군구·복수 지역·날짜·시간·언어·연령 조건을 이해하지 않는다. 구조화 필터와 별도로 문서화했다.
- 지역은 기존 주소 문자열 기반. 표준 행정코드와 주소 정규화는 후속 과제.
- 최대 정원 검사는 잔여석 확인이 아니다. 날짜별 예약 검증은 Spring 예약 흐름에 남아 있음.
- 공개 자료의 장인·공방·수업 관계와 현재 진행자 자격은 추가 검토가 필요. 조사 후보는 실제 입점 상품으로 적재하지 않음.
- 프론트의 새 필터·근거 표시 UI 및 전체 앱 E2E는 미검증.
- 가상 장인·체험은 `[테스트]`로 표시된 로컬 DB에만 존재. 실제 서비스 데이터로 이관하지 않는다.

임시 마이그레이션 검증 DB는 검증 후 삭제했다. 기존 `janginharou`와 Docker 볼륨은 보존했다. API 키는 출력·커밋하지 않았다.
