# 장인·체험 연결 AI: 1차 자료 조사

조사일: 2026-10-18 (한국). 매듭·노리개를 임시 시범 분야로 조사한 초기 기록이다. 이후 사용자 결정으로 **도자기 / 전국 수집 후 지역 필터**로 변경했다. 최신 시범 조사 기록은 [도자기 조사](2026-10-18-pottery-pilot.md)를 따른다. 아래 매듭 사례는 비교용으로 보존한다.

## 결정이 필요한 사항

1. 시범 분야: 매듭·노리개 / 도자기 / 실제 데이터 확보 가능성 우선.
2. 지역: 전국 수집 후 필터 / 수도권 / 특정 지역.
3. 연결 대상: 공식 인정 보유자만 / 이수자·전승교육사 포함 / 일반 전통공예 장인도 포함. 권장안은 모두 포함하되 자격과 확인 상태를 구분하는 것.
4. 첫 연결 방식: 외부 공식 신청 페이지 안내 / 손끝 입점 체험만 추천. 권장안은 외부 자료로 관계를 검증하되 앱 내 예약은 입점·일정 연동된 체험에만 허용하는 것.

## 수집 원칙

- 아래 내용은 원문을 요약한 조사 기록이며 원문 전체 복제나 이용 허락을 의미하지 않는다. 서비스 데이터·RAG 적재 전 출처별 이용조건을 확인한다.
- 과거 행사 이력, 운영 중 여부, 신청 가능 여부, 손끝 입점 여부를 별도로 관리한다.
- 발표 당시 자격을 현재 자격으로 자동 승격하지 않는다. 이수자와 보유자, 인정 예고와 인정 확정을 구분한다.
- 확인되지 않은 가격·대상·강사·언어는 null로 남긴다. 검색 요약문만 확인한 자료는 추가 검토 전 확정 데이터로 쓰지 않는다.
- 기관이나 장인에게 연락하거나 신청하지 않았다. 손끝 제휴·입점 여부도 확인하지 않았다.

## 1. 운현궁 전통매듭 소품 만들기 — 우선 검증 사례

- 출처: 서울문화포털, 서울무형유산교육전시장 제공 행사 안내
- URL: https://culture.seoul.go.kr/culture/culture/cultureEvent/view.do?cultcode=157558&menuNo=200010
- 확인 수준: 본문과 이미지 대체텍스트 확인. 포스터 원본 육안 대조는 미완료.
- 기간: 2026-05-06 ~ 2026-05-27, 수요일 13:00~15:00, 4회 과정.
- 장소: 운현궁 이로당. 대상: 19세 이상. 모집 규모: 10명. 당시 비용: 무료.
- 공고에는 김문희·김지현이 매듭장 이수자로 표기된다. 개별 인물의 현재 자격은 별도 공식 확인 필요.
- 직접 실습 기술: 연봉·도래·가락지·동심결 매듭. 목걸이·팔찌·키링 제작을 안내한다.
- 연결: 프로그램 → 매듭 실습은 명시적 근거 있음. 노리개 자체 제작 프로그램이라는 근거는 없음.
- 상태: 종료. 현재 예약 후보 제외. 손끝 예약·제휴 미확인.
- 검증 용도: 어린이 대상 추천 차단, 일일 체험과 다회 과정 구분, 과거 무료 가격의 현재 적용 차단.

## 기존 코드와 연결할 때 필요한 사항

로컬 코드 확인 기준이며 실제 DB 데이터·운영 상태를 검증하지 않았다.

- Spring `Experience.artisan`으로 장인과 체험이 이미 연결됨. 중복 관계를 새로 만들 필요 없음.
- Spring `ExperienceSchedule`에 날짜·잔여석·활성 상태가 있음. 예약 가능 판단은 이 정보 및 예약 처리 로직으로 확인해야 함.
- Spring 체험에는 가격·시간·언어·태그가 있음. Python 매핑에는 장인 관계·지원 언어·일정이 없어 서버 간 전달 계약 검토 필요.
- 장인 `isVerified`는 앱 승인 처리로 설정된다. 이를 국가·지자체의 보유자 인정과 동일하게 표시하면 안 됨.
- 추가 설계 후보: 기술 식별자, 체험–기술 관계 종류, 관계 근거 URL, 확인일, 공식 자격 종류·발급기관·근거, 외부/입점 구분, 운영 기간·모집 상태.
- Spring 장인에는 사용자 연결이 필수이므로 조사한 외부 인물을 가짜 사용자 계정으로 생성하지 않는다. 조사 후보는 별도 준비 데이터로 유지.

## 다음 조사와 구현 순서

1. 선택 분야·지역에 맞춰 현재 또는 향후 모집 공고와 운영자 공식 안내 확보. 이번 조사에서 현재 예약 가능한 매듭 체험은 확정하지 못함.
2. 포스터와 공식 자격 자료 대조. 인물과 체험의 관계를 필드별로 출처 기록.
3. 수집 후보는 검토 데이터로 저장. 실서비스 DB 삽입·벡터 적재는 아직 하지 않음.
4. 아래 평가 초안에 실제 앱 데이터 ID를 연결하고 현재 응답 기록.
5. 근거 없는 추천 이유 제거 → 조건 필터 → 기술 관계 조회 → 근거 기반 생성 순으로 개발.
