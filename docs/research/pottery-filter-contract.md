# 도자기 조건 검색·연결 근거 계약

2026-10-18 구현. 앱 → Spring → 내부 FastAPI 요청 필드와 응답 확장. 기존 요청 생성자와 응답 기본 필드는 유지한다. 프론트의 새 필터·근거 표시 UI는 아직 구현하지 않았다.

## 요청 예시

```json
{
  "freeText": "청자 상감을 직접 배우고 싶어요",
  "companionType": "FRIEND",
  "headCount": 2,
  "interests": ["도자기"],
  "region": "경기 이천시",
  "maxPrice": 30000,
  "maxDurationMinutes": 90,
  "technique": "상감",
  "locale": "ko"
}
```

- 지역·등록 가격 상한·소요시간 상한·최대 정원 조건을 SQL에서 적용한 뒤 벡터 순위와 top-k를 계산한다.
- 가격은 기존 DB의 `price` 기준이다. 모든 외부 공고의 인당/팀당 가격을 자동 환산하는 기능은 없다. 외부 자료의 가격 단위가 미상인 경우 실제 상품에 임의로 적재하지 않는다.
- `전국`·빈 지역은 지역 제한 없음. 시도 별칭을 정규화하며 시군구는 주소의 독립된 단어로 확인한다. `광주`는 광역시, `경기 광주시`는 경기도 소재 시로 구분한다. 구조화 지역은 행정구역명으로 입력한다.
- 자유문장의 `경기에서`, `서울 지역`, `3만 원 이하`, `30,000원 미만` 같은 제한된 한국어 패턴만 추출한다. 명시된 폼 값이 우선한다. 총예산·소수 금액 등 표현을 해석하지 못하면 예산 확인 안내와 빈 추천을 반환한다. 일반적인 자연어 조건 이해가 완성된 것은 아니다. 날짜·언어·연령·여러 지역 대안은 현재 명시 조건으로 구현하지 않았다.
- `technique` 또는 `heritageItemId`를 지정하면 AI 소유 연결 테이블에서 검토 완료(`verified`) 및 직접 실습(`direct_practice`)인 관계가 있어야 후보가 된다. 미검토 또는 문화적 연관만 있는 관계는 실습 추천에서 제외한다.
- 장인 소속은 기존 Spring `artisan_id` 관계를 사용한다. 이 테이블은 특정 회차를 장인 본인이 진행한다는 증명이 아니며, 공식 자격의 증명도 아니다.

## 응답 확장

- `appliedFilters`: 실제 적용한 구조화 조건.
- `connectionEvidence`: 체험 ID별 문화 항목 ID·기술·관계 종류·근거 URL·요약·확인일. 현재 기술/문화 항목 조건을 명시한 요청에서 반환한다.
- 기존 `answer`, ID 목록, `reasons`, `sources` 등은 유지한다. Spring에서도 필터와 근거를 전달한다.
- 근거가 있는 경우 직접 실습 기술로 추천 이유를 작성한다. 없는 경우 등록 분야만 안내한다. 생성 모델에도 근거와 등록 속성을 전달하지만 모든 생성 문장의 사실성을 자동 증명하지는 않는다.
- 결과 없음과 AI 장애를 구분한다. 장애 중 Spring이 해석할 수 없는 자유문장·지역·기술 조건을 임의로 풀어 기본 상품을 추천하지 않는다.
- 최대 정원은 잔여석이 아니다. 날짜·실시간 예약 가능 여부는 여전히 Spring 예약 단계에서 별도 확인해야 한다.

## 검증 결과

- Python 단위 테스트: 90개 통과.
- 실제 PostgreSQL 합성 데이터 조건·관계 검증: 15개 통과. 광주 지역명 충돌도 포함.
- Spring 추천 테스트: 13개 통과 확인. 테스트 컴파일을 막던 기존 후기 테스트의 누락 import도 수정.
- 실제 임베딩·생성·FastAPI HTTP 경로: `경기에서 3만 원 이하`와 2명·90분 요청에서 테스트 체험 1개 반환, HTTP 200, 답변 생성 성공. 단일 실행 약 5.17초이며 성능 통계가 아니다.
- 실제 장인·예약 전환 효과, 전체 앱 UI, 문장별 인용 정확도, 전국 추천 품질은 미검증.

## 재현

로컬 DB 주소를 환경변수로 지정한 뒤 다음 모듈을 실행한다.

```bash
.venv/bin/python -m scripts.prepare_local_ai_db
.venv/bin/python -m scripts.evaluate_pottery_filters
.venv/bin/python -m scripts.pottery_api_smoke
```

마지막 명령은 실제 모델 API를 소량 호출한다. DB는 로컬 `janginharou`로 제한하며 외부 조사 후보를 자동 입점시키지 않는다. 임시 검증 관계와 주소 변경은 트랜잭션 롤백으로 제거한다.
