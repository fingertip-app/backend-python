# 후기 요약 품질 스펙

> 작성일: 2026-06-16
> 작성자: 김서영
> 목적: AI 후기 요약 API 테스트용 샘플 및 응답 구조 정의

---

## 1. 응답 구조 정의

```json
{
  "summary": "string",
  "sentiment_keywords": {
    "positive": ["string"],
    "negative": ["string"]
  },
  "highlights": ["string"],
  "sentiment": "positive" | "neutral" | "negative"
}
```

| 필드 | 타입 | 설명 |
|---|---|---|
| `summary` | string | 전체 후기를 2~3문장으로 요약 |
| `sentiment_keywords.positive` | string[] | 긍정 키워드 최대 5개 |
| `sentiment_keywords.negative` | string[] | 부정 키워드 최대 5개 |
| `highlights` | string[] | 자주 언급된 특징 최대 3개 |
| `sentiment` | enum | 전체 감성 분류 |

## 2. 리뷰 원문 샘플

### 2-1. 긍정 샘플

**G1 - 도자기 물레 체험**
```
선생님이 정말 친절하게 하나하나 설명해주셔서 처음인데도 너무 재미있었어요.
흙을 직접 만지면서 그릇을 만드는 게 이렇게 힐링이 될 줄 몰랐어요.
완성된 작품을 2주 후에 받을 수 있다고 하는데 너무 기대됩니다.
외국인 친구랑 같이 갔는데 영어 설명도 해주셔서 좋았어요.
강력 추천합니다!
```

**G2 - 매듭 공예 체험**
```
매듭이 이렇게 깊은 역사가 있는 줄 처음 알았어요.
장인 선생님이 조선시대 매듭 문화에 대해 설명해주시는 게 너무 흥미로웠고,
직접 만들어보니 생각보다 어렵지 않아서 뿌듯했어요.
2시간이 금방 지나갔고 만든 작품을 집에 가져갈 수 있어서 좋았습니다.
```

**G3 - 한복 침선 체험**
```
침선이 뭔지도 몰랐는데 체험하고 나서 한복에 대한 시각이 완전히 바뀌었어요.
선생님이 한 땀 한 땀 바느질하는 과정을 보여주시면서 설명해주셨는데
정말 예술이라는 생각이 들었어요. 아이랑 같이 갔는데 아이도 너무 좋아했어요.
체험 공간도 깔끔하고 전통적인 분위기가 잘 살아있었습니다.
```

### 2-2. 중립 샘플

**N1 - 탈춤 체험**
```
탈춤을 배워보고 싶어서 예약했는데 생각보다 짧은 시간이었어요.
기본 동작 몇 가지만 배우고 끝나서 조금 아쉬웠습니다.
선생님은 친절하셨고 탈에 대한 설명도 해주셨어요.
가격 대비 시간이 좀 짧은 것 같아서 아쉽지만 경험 자체는 나쁘지 않았어요.
```

**N2 - 전통주 빚기 체험**
```
막걸리 빚는 과정을 체험해봤어요.
설명은 충분히 해주셨는데 직접 할 수 있는 부분이 생각보다 적었어요.
대부분 보여주시고 설명해주시는 방식이라 좀 더 참여하고 싶었어요.
완성된 막걸리를 시음할 수 있는 건 좋았습니다.
```

**N3 - 국악 해금 체험**
```
해금을 처음 만져봤는데 생각보다 소리 내기가 어려웠어요.
선생님이 잘 가르쳐주시긴 했는데 1시간 안에 뭔가를 배운다는 게 쉽지 않네요.
전통악기에 관심 있는 분들한테는 좋을 것 같아요.
저는 기대치가 너무 높았던 것 같기도 하고요.
```

### 2-3. 부정 샘플

**B1 - 도자기 체험**
```
예약하고 갔는데 장인 선생님이 안 계시고 다른 분이 진행하셨어요.
설명도 부족하고 준비도 제대로 안 된 것 같아서 많이 실망했어요.
가격도 비싼 편인데 이 정도면 너무 아쉽습니다.
다시 방문할 것 같지는 않아요.
```

**B2 - 한지 공예 체험**
```
위치 찾기가 너무 힘들었고 주차도 불편했어요.
체험 내용 자체는 나쁘지 않았는데 공간이 너무 좁고 환기가 잘 안 됐어요.
여름에 방문했는데 에어컨도 없어서 많이 더웠습니다.
체험보다 환경적인 부분이 너무 불편해서 좋은 기억으로 남지 않네요.
```

**B3 - 농악 체험**
```
사진으로 봤던 것과 실제가 너무 달랐어요.
설명도 거의 없이 악기만 쥐어주고 따라치라는 식이라 뭘 배우는 건지 모르겠더라고요.
시간도 30분밖에 안 됐고 가격은 비쌌어요.
외국인 친구 데려갔는데 설명을 전혀 못 알아들어서 민망했어요.
```

## 3. 기대 응답 예시

### G1 (긍정) 기대 결과
```json
{
  "summary": "친절한 설명과 함께 흙을 직접 만지며 그릇을 만드는 힐링 체험으로, 외국인도 즐길 수 있는 영어 안내가 인상적이었습니다. 완성 작품을 수령할 수 있어 만족도가 높은 체험입니다.",
  "sentiment_keywords": {
    "positive": ["친절한 설명", "힐링", "재미있음", "영어 안내", "작품 수령"],
    "negative": []
  },
  "highlights": ["친절한 강사", "외국인 동반 가능", "작품 제작 후 수령"],
  "sentiment": "positive"
}
```

### N1 (중립) 기대 결과
```json
{
  "summary": "친절한 강사와 기본적인 탈춤 동작을 배울 수 있었으나, 체험 시간이 짧아 아쉬움이 남는다는 의견이 있습니다.",
  "sentiment_keywords": {
    "positive": ["친절한 선생님", "탈 설명"],
    "negative": ["짧은 시간", "가격 대비 아쉬움"]
  },
  "highlights": ["기본 동작 학습", "짧은 체험 시간"],
  "sentiment": "neutral"
}
```

### B1 (부정) 기대 결과
```json
{
  "summary": "장인 대신 다른 진행자가 체험을 운영해 기대에 미치지 못했으며, 설명 부족과 준비 미흡으로 실망스러웠다는 평가입니다.",
  "sentiment_keywords": {
    "positive": [],
    "negative": ["장인 부재", "설명 부족", "준비 미흡", "비싼 가격", "재방문 의사 없음"]
  },
  "highlights": ["장인 부재", "준비 미흡"],
  "sentiment": "negative"
}
```

## 4. Fallback 처리 기준

| 케이스 | 처리 방식 |
|---|---|
| 빈 리뷰 (`""`) | `summary: ""`, `sentiment: "neutral"`, 나머지 빈 배열 반환 |
| 10자 미만 짧은 리뷰 | 원문 그대로 `summary`에 반환, 키워드 추출 생략 |
| 개인정보 포함 (전화번호·이메일) | 마스킹 후 처리 또는 해당 문장 제외 |
| OpenAI 호출 실패 | `{"error": "요약 서비스를 일시적으로 사용할 수 없습니다."}` 반환 |
