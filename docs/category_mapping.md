# 문화유산 Category ↔ 체험 Category 매핑

> 작성일: 2026-06-16
> 작성자: 김서영
> 목적: RAG 해설 결과에서 관련 체험 카드를 추천할 때 사용할 카테고리 매핑 기준

---

## 1. 흐름

```
질문 → RAG 검색 → heritage_items.category → 매핑 → Experience tags → 체험 카드 반환
```

Experience.category 단일 컬럼이 아닌 태그 기반 매칭으로 확정 (2026-06-08 팀 결정).

---

## 2. 체험 카테고리 정의

| 태그 | 설명 |
|---|---|
| `craft` | 전통 공예 (도자기, 매듭, 자수, 나전칠기, 한지, 목공예 등) |
| `hanbok` | 전통 복식·의복 (한복, 침선, 자수 등) |
| `music` | 전통 음악·소리 (국악, 민요, 농악, 판소리 등) |
| `dance` | 전통 춤·무용·무예 (탈춤, 검무, 처용무, 택견 등) |
| `food` | 전통 음식·주류 (김치, 막걸리, 전통주, 한과 등) |
| `performance` | 전통 공연·놀이·연희 (탈놀이, 줄타기, 사자놀음 등) |

> 의례·의식은 RAG 지식베이스로는 활용하되 체험 태그 직접 매핑은 post-MVP.

---

## 3. 무형유산 종목 대분류 → 체험 태그 매핑

| 무형유산 대분류 | 체험 태그 | 비고 |
|---|---|---|
| 공예기술 | `craft` | |
| 복식·의복 | `hanbok`, `craft` | 자수는 양쪽 해당 |
| 음악 | `music` | 악기장은 `craft`도 병행 |
| 무용·무예 | `dance` | |
| 음식·주류 | `food` | |
| 의례·의식 | — | post-MVP |
| 놀이·연희 | `performance` | |

---

## 4. 엣지 케이스

| 종목 | 이슈 | 처리 방식 |
|---|---|---|
| 자수 | 공예기술이지만 한복 맥락에서도 사용 | `craft` primary, `hanbok` secondary |
| 탈춤 | 무용이지만 탈 제작은 공예 | 체험 행위 기준으로 분류 (탈춤 체험 → `dance`, 탈 제작 체험 → `craft`) |
| 악기장 | 악기 제작은 공예, 연주는 음악 | `craft` primary, `music` secondary |

---

## 5. 유사도 임계값 기준

| 코사인 유사도 | 처리 |
|---|---|
| ≥ 0.75 | 추천 체험 노출 |
| 0.60 – 0.74 | "이런 체험도 있어요" 보조 추천 |
| < 0.60 | 미노출 |

---

## 6. 임베딩 입력 기준

**무형유산 데이터 (khs.go.kr)**
```
{종목명} {보유자명} {content 본문}
```

**체험 데이터 (Experience)**
```
{title} {description} {tags}
```
